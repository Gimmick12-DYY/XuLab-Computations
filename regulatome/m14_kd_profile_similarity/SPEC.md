# m14_kd_profile_similarity: do TFs that bind together in HITAG also act together in Perturb-seq? (spec, 2026-11-12)

Label: diagnostic, benchmark-developed. HEK293T. Written and committed before any number is computed; corrections only by appended amendments.

1. Knockdown similarity K(i,j). Double-centred response matrices of the two random halves of cells (m15 "dc" reading: Arm 2, genes detected in >= 10% of NTC cells, each half double-centred on its own). Both TFs' own genes removed for the pair (HP1: CBX1/3/5; ZUFSP: ZUP1). K = mean of Spearman(TF_i half 1, TF_j half 2) and Spearman(TF_i half 2, TF_j half 1) over genes. Also K on the 2,000 genes with the highest variance across TFs in the all-cell double-centred matrix.
   TF sets: primary = TFs with split-half reliability >= 0.2 (m7 tf_folds.tsv ceiling); secondary = the 10 strong-phenotype TFs (m16); tertiary = all 76 TFs with a knockdown.
2. Binding similarity B(i,j), reused as built: the five ChromHMM element-set percentile matrices behind complex_screen/candidates_frozen_v1 (af3_corr060_20261104/align_corr_20261109/inputs/pct_{all,noquies,tss,enhancer_biv,repressive}.tsv; sha256 recorded). Primary B = mean of the five; secondary = each separately. The uncorrected Pearson matrix is used only if its file is found on Longleaf; otherwise reported as not located.
3. Positive control, evaluated first, on all 76 TFs: named pairs present with a knockdown for both TFs: RBBP4-RBBP7, MBD3-RBBP4, MBD3-RBBP7, EZH2-MTF2, PCGF6-EZH2, PCGF6-MTF2, MEF2A-MEF2D, NFYA-DR1, CTCF-STAG2, HP1-SETDB1; plus every pair with known = True in complex_screen/candidates_frozen_v1/candidates_all3081.tsv (reported also without the NEUROD4-rule pairs). Statistic: mean K of the control pairs minus mean K of random pairs matched on both TFs' reliability tertile and cell-number tertile (10,000 matched random sets; one-sided permutation p; bootstrap interval over control pairs). Pass = p < 0.05. If it fails, every verdict below is UNINFORMATIVE, not negative; all numbers are still reported.
4. Main test: Mantel correlation (Spearman) between B and K over TF pairs, TF-label permutation p (10,000). Partial Mantel: rank B and rank K each residualised on (a) product and absolute difference of log cells, (b) same depth tertile, (c) absolute difference and product of knockdown reliability; Spearman of residuals, permutation p over TF labels. Control matrix: depth alone (minus absolute difference of log cells, and product of log cells) against K. A pseudo-TF binding similarity matrix does not exist as built and is not constructed (stated).
5. Secondary (each reported whatever it gives): K for TF pairs sharing higher-order coordinated binding module regions (cobinding/results/ourrun_k50_clique_hubs_blacklist_removed_loop_edges/tf_pair_shared_regions.tsv, p < 0.05) vs other pairs; K for the 1,732 frozen candidate pairs vs non-candidate pairs (best_pct < 0.60), stratified by cell-number tertile pair; K by AF3 5-seed tier (strong / weak / none or not run; af3_corr060_20261104/rescore_5seed/tiers_5seed.tsv), with DNA-test DISPLACED pairs flagged (af3_dna_included_20261111/results.tsv); K for CAP-SELEX called pairs vs the rest.
6. Direction check: top 20 pairs by rank-sum of B and K; per pair B, K, number of shared reproducible responders (|z| >= 2 in both halves, same sign within each TF; raw per-TF z halves), fraction of shared responders moving in the same direction under both knockdowns, and known yes/no.
7. Outputs: tables; scatter of B vs K (all 76-TF pairs; known and AF3-strong pairs marked; top pairs labelled); clustered heatmaps of B and K for the primary set in the same TF order (order from clustering K). Versions looked at: K (all genes, top-2,000 variable) x B (mean + 5 single matrices) x TF set (3) = 36 Mantel tests, all reported; no best-of selection.
