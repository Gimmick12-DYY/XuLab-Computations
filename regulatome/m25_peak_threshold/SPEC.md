# m25_peak_threshold: is the q005 cutoff too strict for shallow TFs? (spec, 2026-11-12)

Label: diagnostic. HEK293T. Tables only, no plots. Committed before any number is computed.

Finding from the code, before numbers: the m11 "P_raw_lab" input (m11_shared.py) is the lab MACS2 narrowPeak file as called (p < 0.01, no q filter), mapped to canonical elements by summit; the shared 1-kb bins were used only to flag HOT regions. E3 (requested as "the m11 shared 1-kb-bin re-call") is therefore identical to E1 and is not computed separately.

1. Edge definitions, all from our data with the same canonical ABC links (ABC >= 0.02, self-promoter included), strongest summit per element: E0 = lab q005 summits (current); E1 = lab peaks as called (p < 0.01); E2 = top N as-called peaks per TF by signalValue, N = 2,000, 5,000, 10,000, 20,000. Six definitions in total. For each: genes with an edge per TF, fraction of edges with a promoter peak, TF x TF Jaccard (median off-diagonal; the deep pairs NFYA-RBBP4, RBBP4-SOX4).
2. Choice rule, not based on Perturb-seq. Motif TFs (31, HOCOMOCO v11 as in m10): fraction of edge elements whose peak summit has the own motif within +/- 50 bp (FIMO p < 1e-4, sequence names without ":", exit codes checked), minus the fraction in a GC-decile-matched background of union ATAC peak centres; the same with a swapped motif (next motif TF, cyclic) as a negative control. ChIP TFs (CTCF HEK293T and HEK293, NFYA K562, MAZ/ZBTB7A/ZIC2/ZNF282/ZNF777 HEK293): fraction of edge elements overlapping ChIP peaks minus the median over the other TFs' edge elements under the same definition. Pooled paired difference of each definition minus E0, TF-bootstrap 95% interval (2,000), overall and by depth tertile. A definition "is better than q005" only if the motif and ChIP differences both have intervals not below 0 AND the number of edges of low-tertile TFs increases.
3. Check only, not used for choosing: for each definition, the m22 high-confidence pair comparison (K = 500 and 2,000; bound fraction own vs swapped vs matched, pooled with and without E4F1/NRF1/DNMT1, and per TF), and the per-TF and whole-matrix simple correlation point estimates (score vs |z|, raw and within-TF percentile).
All six definitions are reported.
