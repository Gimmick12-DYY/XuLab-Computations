2. TF x gene tables from peaks only (no fragments). Primary version: set (a) as called (p < 0.01, the lab caller's threshold), no added filter. Second version: q <= 0.05 (set (b)). Links: canonical ABC HEK293T_hicfixed, ABC >= 0.02, self-promoter included, flagged promoter (isSelfPromoter) vs distal. Peak at an element = summit inside the element; element strength = max signalValue (column 7) of such peaks, and their max -log10 q (column 9). Per TF and gene (genes = canonical ABC GeneList): n linked elements, n linked elements with a peak, promoter peak yes/no, sum over links of signalValue x ABC.Score (all, promoter-only, distal-only), any-peak flag. Outputs: long table and wide TF x gene matrix of the summed score (TSV.gz) per version; per-TF summary (genes with nonzero score, share of the gene list); per TF, peaks whose summit lies in no candidate element (dropped) and, of those, how many are within 1 kb of a TSS.
