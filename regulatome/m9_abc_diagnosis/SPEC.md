# Why do canonical ABC targets not match Perturb-seq? Step 1 of the diagnosis (2026-11-11)
Question for this step only: is the limit in the benchmark, in how targets are called, or in our binding input? Nothing is tuned here.
Common setup: knockdown matrix kd_response out_v2, Arm 2 (Arm 1 beside it), genes >= 10% NTC detection. Response read three ways: (r1) raw per-TF z; (r2) double-centred z as in B6; (r3) z after removing the leading shared components, defined in D below. Gene universe: ABC genes in the matrix. TFs: all testable TFs, with a separate table for those with knockdown ceiling >= 0.2. Statistics per TF and target definition: Fisher OR of targets vs top-5% |z| responders (as in abc_canonical/SPEC.md); and a threshold-free one, Spearman between the continuous target score and |z|, and with signed z. Every statistic is given beside the same statistic for an accessibility-matched control set or score (promoter ATAC decile x CpG-island matched genes, 200 draws) and for a mis-paired TF.
A. Target-set description for the existing canonical ABC run (HEK293T_hicfixed): per TF, number of peaks at q <= 0.05, bound candidate elements, target genes, fraction of the universe called a target, fraction of targets reached only through a promoter element / only through distal links; median Jaccard between TFs' target sets; the same counts for the ATAC-only control. Table sorted by cells per TF.
B. Benchmark positive controls that owe nothing to our binding. (B1) Motif targets: for each testable TF with a motif in HOCOMOCO v11 (the collection behind TF1000cells_motifs.xlsx), scan each gene's promoter (TSS +/- 500 bp) with FIMO; continuous score = max log-odds; target set = top 1,000 genes by score, and separately all genes with a hit at p < 1e-4. Control: the same motif shuffled (dinucleotide-preserving, 20 shuffles) in addition to the matched-gene control. (B2) Bulk ChIP targets for the TFs with bulk ChIP on Longleaf (the 7-TF truth set; state the cell line of each reference, HEK293T or HEK293 or other): continuous score = ChIP signal at the promoter; target set = top 1,000. (B3) Chromnitron predictions (/users/x/u/xujie/HEK293T_SA, read only) at promoters for its TFs, same two definitions. List which TFs each source covers.
C. The same statistics for our HITAG binding at promoters only, no ABC: raw and imputed, each as (i) log1p CPM, (ii) per-TF rank, (iii) standardised: per-TF rank minus the gene's mean rank over the other 78 TFs. Top 1,000 and continuous. And the existing canonical ABC target sets (hicfixed, powerlaw) on the same footing.
D. Shared structure of the response: SVD of the testable-TF x gene z matrix (raw per-TF z, genes standardised); variance explained by components 1 to 10; Spearman of each of the first 5 gene loadings with promoter ATAC, promoter H3K27ac, NTC expression level and CpG-island status; per-TF loading on component 1 against knockdown ceiling and KD-cell count. r3 = z with components removed, for k = 1, 2, 3, 5 (all reported, none selected). If the full X-Atlas/Orion matrix beyond the panel TFs is not on Longleaf, say so; use the panel matrix.
E. One summary table: rows = target definitions (motif top-1,000, motif p < 1e-4, bulk ChIP, Chromnitron, HITAG raw i/ii/iii, HITAG imputed i/ii/iii, canonical ABC hicfixed, canonical ABC powerlaw, ATAC-matched control, mis-paired), columns = median OR and fraction of TFs with OR above their matched control, mean Spearman with |z| and with signed z (sign fitted on no data: report signed and absolute), for r1, r2 and r3(k=1,2,3,5), for all testable TFs and for ceiling >= 0.2. Plus per-TF rows for NRF1, NFYA, E4F1, NME2, XPA, CTCF, ZNF143, MAZ, E2F3, MLX, SOX4, DDIT3 and every other TF with ceiling >= 0.2.
