# m22_edge_table: the HEK293T Regulome edge table (spec, 2026-11-12; incorporates the user's changes of 2026-11-12)

The Regulome is defined from our HITAG data only, with HEK293T ATAC, H3K27ac and Hi-C as auxiliary inputs for element-gene links (canonical ABC, ABC >= 0.02, self-promoter included). Perturb-seq never defines an edge; it appears only as external columns. Label for any column compared with Perturb-seq: diagnostic.

1. Edge: one row per (TF, gene) for every gene of the 11,228-gene universe with a linked q005 peak of that TF (promoter element or ABC-linked distal element), all 79 TFs. One definition, no classes; TFs sharing target genes are kept as they are.
2. Binding columns: promoter peak yes/no and signalValue; number of linked distal elements with a peak; best ABC score and its distance to the TSS; score = sum of signalValue x ABC over bound elements; percentile of the gene within the TF; promoter reads CPM (TSS +/- 500 bp).
3. Combined-panel columns (descriptive results, never filters): shared_by = number of the 79 TFs with a linked peak at the gene; co_bound_tfs = their names; panel_relative_ratio = this TF's CPM at the gene's promoter and linked elements / mean CPM of the other 78 TFs (descriptive only); partner TFs from the frozen candidate list bound at the same element; Figure 3 higher-order coordinated binding module of the bound element where available (as built).
4. Background column: enrichment_over_background per bound element = this TF's reads / expected reads from ATAC, the expectation fitted per TF as a negative-binomial regression of element reads on log ATAC RPM (and element width) over open canonical elements; ratio and upper-tail p. Gene-level = maximum over the gene's bound elements. The IgG CUT&Tag sample under /vast/som/xujie_lab/CUT&Tag/ is inspected read-only (files, read count, genome build, any metadata naming the cell line) and is not used until the user confirms it is HEK293T; the code accepts it as an alternative background.
5. Check of the background column (not a definition): for TFs with an own motif, the fraction of own-motif promoters among the top-enriched bound genes (top 1,000 by enrichment_over_background) vs the top 1,000 by raw signalValue x ABC; for TFs with bulk ChIP, the same for ChIP-bound genes; paired over TFs, median difference with TF-bootstrap 95% interval. If the interval is not above 0, the column is labelled "not validated" and predicted_impact uses plain signalValue x ABC.
6. predicted_impact (ours): score from 2, and the TF's share of the summed score of all TFs bound at that gene (so TFs at one gene can be compared); also on the background-corrected signal if 5 passes.
7. observed_kd, external (X-Atlas/Orion HEK293T): Arm 2 raw per-TF z (all cells), z in each half, reproducible flag (|z| >= 2 in both halves, same sign), the TF's knockdown reliability and strong-phenotype flag; NA for TFs without a knockdown; observed_kd_top25 from m23 when available.
8. Agreement check, not a definition: within genes with >= 3 bound TFs that have a usable knockdown, Spearman of predicted_impact share vs |observed_kd| across TFs, mean over genes with gene-bootstrap interval; within TFs, Spearman over bound genes, mean over TFs with TF-bootstrap interval; both with the swapped-TF control (m7 mis0) replacing predicted_impact.
9. TF x TF Jaccard of target lists reported as a description of shared regulation, with the caveat (m20) that part of it reflects open-chromatin background.
10. Outputs: regulome_edges.tsv.gz; per-TF summary; per-gene summary; lookup scripts tf2genes.py TF and gene2tfs.py GENE; first views for genes HSPB1, PGAM1, MYC, TXNIP (published-style locus view; per TF a bar of predicted_impact from our data and a separate aligned bar of observed_kd marked external) and TFs NRF1, E4F1, CTCF, NFYA, MLX.

## Amendment 1 (2026-11-12, before any number): simple correlation of the ABC score with Perturb-seq (tables only)
Diagnostic. Score matrix S = sum of q005 peak signalValue x ABC over a gene's linked elements (0 where no edge), TFs with a knockdown x the 11,228 expressed genes, each TF's own gene removed. Perturb-seq: Arm 2 raw per-TF z (all cells; and the corrected top-25% sgRNA matrix of m23 as a second version), and the double-centred response.
Whole matrix, first: Spearman and Pearson between S and |z|, and between S and signed z, over all (TF, gene) entries, three ways: (1) raw pooled; (2) each TF row standardised (mean 0, sd 1) in both matrices; (3) each TF row converted to within-TF percentiles in both. Controls: swapped-TF matrix (S rows permuted within depth tertile, 1,000 permutations; permutation p = fraction of permutations >= observed) and the ATAC-only score matrix (sum of element ATAC RPM x ABC, the same row for every TF). TF-block bootstrap 95% interval (2,000 resamples of TFs).
Per TF (simple_correlation.tsv): Spearman and Pearson of S with |z|, signed z and the double-centred response over all expressed genes; gene-bootstrap 95% interval for Spearman with |z|; the same over bound genes only; point-biserial with the binary edge; controls ATAC-only score and swapped TF (m7 mis0, same depth tertile); reliability ceiling; number of bound genes; strong-phenotype flag; version column. Must reproduce m11 (NRF1 about 0.046, CTCF about 0.003); a discrepancy is reported.

## Amendment 2 (2026-11-12, before any number): high-confidence Perturb-seq pairs vs the Regulome (tables only)
Diagnostic. Halves = m15 double-centred halves (Arm 2, genes >= 10% NTC detection, own gene removed).
High-confidence sets, K = 100, 500, 2,000: (primary, as requested) pairs in the top K of |z| over the whole TF x gene matrix in half 1 AND in the top K in half 2, with the same sign; (reference) the m15 "union" definition (top K in one half confirmed in the other half's per-TF top 5%), which gave 140 pairs from 17 TFs at K = 100; the difference is reported.
Per set, overall and per TF: n pairs; fraction with an edge of the knocked-down TF (any linked q005 peak) and with a promoter peak; controls (a) swapped TF = the mean fraction over all other TFs of the same depth tertile bound at the same gene, (b) the same TF at matched non-responder genes (NTC expression decile x promoter ATAC decile x CpG; 20 draws per pair). Odds ratio of an edge, high-confidence pairs vs matched non-responders, with a pair bootstrap and a TF-clustered bootstrap (2,000 draws); also without E4F1, NRF1 and DNMT1; split by direction (gene down vs up on knockdown).
Reverse reading: among bound high-confidence pairs, the within-TF percentile of the score among that TF's bound genes, vs bound non-responder genes of the same TF (Mann-Whitney).
List of bound high-confidence pairs (TF, gene, z, halves, promoter/distal, score, shared_by) as example candidates. No views.

## Amendment 3 (2026-11-12, before any number): does predicted share follow depth? (tables only; no views)
1. Per TF (71 with edges): mean and median predicted_impact_share_at_gene over its bound genes, and mean score (signalValue x ABC) over bound genes; Spearman over TFs with log10 cells and log10 fragments, TF-bootstrap 95% interval; number of genes at which each TF has the top share.
2. Two alternative impact columns from our data only: within_tf_percentile = percentile of the gene's score among that TF's bound genes; depth_scaled_share = share at the gene after dividing each TF's scores by that TF's median score over its bound genes.
3. Check, not a definition: within-gene Spearman of each version (share, within_tf_percentile, depth_scaled_share) vs external |z| (all cells; the top-25% matrix was not adopted in m23), genes with >= 3 bound TFs that have a knockdown, with the swapped-TF control (m7 mis0) and gene-bootstrap intervals; and the fraction of genes whose top TF under each version has a reproducible knockdown effect on the gene (|z| >= 2 in both halves, same sign), against the chance rate (mean over genes of the fraction of bound TFs with a reproducible effect). All three versions are reported; none is chosen by its agreement with Perturb-seq.

## Amendment 4 (2026-11-12, user's choice, before any number): primary peak definition = top 5,000 per TF
- Edge = one of the TF's top 5,000 lab peaks (as called by MACS2, p < 0.01) ranked by signalValue, with its summit in the gene's promoter element or an ABC-linked element (canonical ABC, ABC >= 0.02, self-promoter included); strongest summit per element. Ties in signalValue are broken by file order (first occurrence), as in m25 "E2_top5000". All 79 TFs have >= 5,000 called peaks, so no TF is short.
- regulome_edges.tsv.gz becomes the top-5,000 table (primary). The q005 table is kept as regulome_edges_q005.tsv.gz for reference (m25 comparisons cite it).
- Unchanged: ATAC background column (not validated), IgG off; Perturb-seq only in external columns (all cells and top-25% sgRNA cells); shared targets kept, shared_by and co-bound TFs as result columns; three impact versions (share, within-TF percentile, depth-scaled share).
- Re-run on the new table (tables only): lookups (NRF1, E4F1, CTCF, NFYA, MLX; HSPB1, PGAM1, MYC, TXNIP), the high-confidence pair table (Amendment 2), the per-TF and whole-matrix simple correlation point estimates (Amendment 1), the share-vs-depth summary (Amendment 3), and a candidate example table: genes with >= 3 bound TFs where a bound TF has a reproducible external knockdown effect.
