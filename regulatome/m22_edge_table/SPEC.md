# m22_edge_table: the HEK293T Regulome edge table (spec, 2026-11-12; incorporates the user's changes of 2026-11-12)

The Regulome is defined from our HITAG data only, with HEK293T ATAC, H3K27ac and Hi-C as auxiliary inputs for element-gene links (canonical ABC, ABC >= 0.02, self-promoter included). Perturb-seq never defines an edge; it appears only as external columns. Label for any column compared with Perturb-seq: diagnostic.

1. Edge: one row per (TF, gene) for every gene of the 11,228-gene universe with a linked q005 peak of that TF (promoter element or ABC-linked distal element), all 79 TFs. One definition, no classes; TFs sharing target genes are kept as they are.
2. Binding columns: promoter peak yes/no and signalValue; number of linked distal elements with a peak; best ABC score and its distance to the TSS; score = sum of signalValue x ABC over bound elements; percentile of the gene within the TF; promoter reads CPM (TSS +/- 500 bp).
3. Combined-panel columns (descriptive results, never filters): shared_by = number of the 79 TFs with a linked peak at the gene; co_bound_tfs = their names; panel_relative_ratio = this TF's CPM at the gene's promoter and linked elements / mean CPM of the other 78 TFs (descriptive only); partner TFs from the frozen candidate list bound at the same element; Figure 3 higher-order coordinated binding module of the bound element where available (as built).
4. Background column: enrichment_over_background per bound element = this TF's reads / expected reads from ATAC, the expectation fitted per TF as a negative-binomial regression of element reads on log ATAC RPM (and element width) over open canonical elements; ratio and upper-tail p. Gene-level = maximum over the gene's bound elements. The IgG CUT&Tag sample under /vast/som/xujie_lab/CUT&Tag/ is inspected read-only (files, read count, genome build, any metadata naming the cell line) and is not used until the user confirms it is HEK293T; the code accepts it as an alternative background.
5. Check of the background column (not a definition): for TFs with an own motif, the fraction of own-motif promoters among the top-enriched bound genes (top 1,000 by enrichment_over_background) vs the top 1,000 by raw signalValue x ABC; for TFs with bulk ChIP, the same for ChIP-bound genes; paired over TFs, median difference with TF-bootstrap 95% interval. If the interval is not above 0, the column is labelled "not validated" and predicted_impact uses plain signalValue x ABC.
6. predicted_impact (ours): score from 2, and the TF's share of the summed score of all TFs bound at that gene (so TFs at one gene can be compared); also on the background-corrected signal if 5 passes.
7. observed_kd, external (X-Atlas/Orion HEK293T): Arm 2 raw per-TF z (all cells), z in each half, reproducible flag (|z| >= 2 in both halves, same sign), the TF's knockdown reliability and strong-phenotype flag; NA for TFs without a knockdown; observed_kd_top25 from m23 when available.
8. Agreement check, not a definition: within genes with >= 3 bound TFs that have a usable knockdown, Spearman of predicted_impact share vs |observed_kd| across TFs, mean over genes with gene-bootstrap interval; within TFs, Spearman over bound genes, mean over TFs with TF-bootstrap interval; both with the swapped-TF control (m7 mis0) replacing predicted_impact.
9. TF x TF Jaccard of target lists reported as a description of shared regulation, with the caveat (m20) that part of it reflects open-chromatin background.
10. Outputs: regulome_edges.tsv.gz; per-TF summary; per-gene summary; lookup scripts tf2genes.py TF and gene2tfs.py GENE; first views for genes HSPB1, PGAM1, MYC, TXNIP (published-style locus view; per TF a bar of predicted_impact from our data and a separate aligned bar of observed_kd marked external) and TFs NRF1, E4F1, CTCF, NFYA, MLX.
