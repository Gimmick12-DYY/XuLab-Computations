# Alternative benchmarks: coverage table (spec, 2026-11-11)
Ask (Yuyang, relayed verbatim): "I think this is the best we can get for HEK293T cell line.. propose something else for us to make the comparison maybe?" This folder produces a COVERAGE table only: for each of the 79 panel TFs, which alternative benchmark data exist. No comparison statistic against our binding is computed here. Only public downloads and metadata queries are used; nothing about the project is sent to outside services.
Alias handling: HP1 = CBX1/CBX3/CBX5; ZUFSP = ZUP1; HOCOMOCO v11 uses UniProt entry names (m9 mapping); otherwise the HGNC symbol.
1. ChIP: ENCODE (metadata API: TF ChIP-seq experiments, released, by biosample HEK293T / HEK293 / other, with accession, target label, tag from the target or construct label, and whether a released bed narrowPeak file exists); ChIP-Atlas experimentList.tab (hg38, antigen class TFs and others, cell type HEK293T / HEK293 / other); GEO GSE78099 sample list (Imbeault/Trono KZFP ChIP-exo, HEK293T; supplementary peak files per sample). HEK293T and HEK293 are counted separately and never merged. Already on Longleaf: downstream/tracks/bulk_chipseq (8 sets) and Chromnitron predictions (43 TFs).
2. Motif: HOCOMOCO v11 full (own motif, as m9), HOCOMOCO v12 core and JASPAR 2024 core vertebrates (motif_analysis/cache/motifdb, name match), and the own-motif entries of TF1000cells_motifs.xlsx (sheet TF1000cells_motifs: p-values per method; the workbook stores p-values, not ranks).
3. Curated targets: CollecTRI and DoRothEA (A-C) from the OmniPath web service, TRRUST v2 human raw data; downloaded to XuLab/data/external/tf_targets/ with URL, date and sha256; per TF: targets, targets in the 11,228-gene universe (m9 Arm 2), signed targets.
4. Other perturbation data (lists only, no expression matrices): Replogle 2022 (K562 genome-wide, K562 essential, RPE1) from figshare metadata/supplementary lists; KnockTF 2.0 dataset list; ENCODE shRNA / CRISPRi / CRISPR RNA-seq experiments (HepG2, K562) from the ENCODE API. X-Atlas HCT116 is not touched. A source that cannot be reached or parsed is left NA and named.
5. Own expression in HEK293T: NTC detection rate and mean log1p(CP10k) of the TF's gene in the Arm 2 knockdown matrix (out_v2 npz, all 18,151 genes).
Carried columns: cells, depth tertile, specificity tier (d >= .04), knockdown ceiling, benchmark-testable flag (m10 Amendment 1). Summary: per option, TFs covered of 79 and of the 20 claim-tier TFs, named. Outputs: coverage.tsv, coverage_summary.tsv, sources.tsv, README.txt; copy to /Users/dyy/Desktop/HEK293T-ATGTAG/perturbseq_matrix/alt_benchmarks/.
