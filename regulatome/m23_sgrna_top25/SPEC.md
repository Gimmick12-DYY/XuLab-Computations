# m23_sgrna_top25: top-25% sgRNA cells as the Perturb-seq benchmark (spec, 2026-11-12)

Label: diagnostic, benchmark-developed. HEK293T. Committed before any number is computed.

0. Finding from the code, no new numbers: the existing Arm 1 (m4 kd_response_v2.py) keeps a cell if its summed sgRNA UMI is >= the Q3 of Non-Targeting cells in the same GEM batch, for targeted and NTC cells alike, and keeps a unit only if >= 50 cells remain. The cut is therefore relative to the NTC sgRNA distribution, not the top 25% of each perturbation's own cells; for many guides almost no targeted cell clears it (e.g. PA2G4 124 -> 1 cell), which is why only 30 of 81 knockdown TFs survive (49 would survive at >= 25 cells). The X-Atlas/Orion text describes selecting the top 25% of cells by sgRNA expression per perturbation.
1. New matrix "top25_own": for each knockdown unit, the top 25% of its own pass_guide_filter cells by summed sgRNA UMI, ranked within GEM batch (ties at random, seed 20261112); NTC reference = all NTC cells of the same GEMs (primary) and, as a sensitivity, NTC top 25% by sgRNA UMI within GEM. Units kept with >= 25 cells. Same response and z definition as m4 v2 (GEM-weighted mean log1p CP10k vs NTC, within-GEM NTC variance), raw per-TF z and double-centred z, genes with >= 10% NTC detection; halves drawn within the retained cells by GEM.
   Control "random25": a random 25% of each unit's cells (same per-GEM counts as top25_own), same processing, 3 draws.
2. Per TF, all cells vs top25_own vs random25: cells, on-target knockdown of the TF's own gene (log2 fold change of own-gene mean vs NTC), split-half reliability (Spearman-Brown of the half-to-half correlation after removing gene means, as m7), reproducible responders (|z| >= 2 in both halves, same sign), and the m16 strong-phenotype classifier rerun on the retained cells with the same settings. Paired summaries over TFs (median difference, TF-bootstrap 95% interval) for top25_own minus all and top25_own minus random25.
3. Same lists, no new list building: m16 simple model (pooled MH OR for strong TFs and the rest; per-TF OR with intervals for NRF1, E4F1, CTCF, DNMT1 and the other strong TFs) and m19 B1/B2 x P1/P4 with swapped-TF and matched-gene controls, on all-cell vs top25_own, side by side.
4. observed_kd_top25 (z, halves, reproducible flag) is exported for the m22 edge table.
Which version is more reliable is read per TF and overall from section 2 only; no per-TF choice of the version that agrees better with binding.

## Amendment 1 (2026-11-12, before any number): m14 positive control on three matrix versions
Repeat only the m14 positive control (same named and known pair lists, same cross-half Spearman similarity on double-centred halves, same matching on reliability and cell-number tertiles, 10,000 matched random sets) on: all cells (as in m14), top25_own, and random25 (first draw). Report mean similarity of control pairs vs matched random pairs with interval and p for each version, and per-pair values for the 9 named pairs. Only if the control passes on top25_own (p < 0.05) AND its control-minus-random difference exceeds that of random25, rerun the m14 main Mantel test and secondary comparisons on top25_own; otherwise report "still uninformative" and run nothing further at pair level.

## Amendment 2 (2026-11-12): selection fixed after a definition error, before results are reported
The first run ranked cells within each GEM batch and kept ceil(25%) per batch; with 1-3 cells of a perturbation per batch this kept about half of the cells (e.g. ZNF367 41 of 45), so it was not a top-25% selection. Replaced by: for each knockdown unit, each cell's summed sgRNA UMI is converted to its percentile among all cells of its GEM batch (to remove batch depth), and the top round(25%) of the unit's cells by that percentile are kept (ties at random, seed 20261112). random25 = the same number of the unit's cells drawn at random (3 draws). Everything else in the SPEC and Amendment 1 is unchanged. The first run's outputs are overwritten.
