## Amendment 1 (2026-11-18, user: would MACS peak calling on the imputed data do better than bins? written before any number)
Per knockdown TF (63), from the unified imputer output: if matrix_csr.npz.pre_openmask exists and holds the current imputation (its non-zeros >= the masked matrix's raw calls), it is used (genome-wide 1 kb bins, before the open-chromatin mask); otherwise the masked matrix (104,738 ATAC bins). Which one is used is reported per TF.
Pseudobulk = positive cells per 1 kb bin. ATAC = HEK293T OmniATAC Tn5 tags (m2_abc/inputs/omniatac_merged.tn5.tagAlign.gz) counted per 1 kb bin. MACS3 3.0.3 (module macs3/3.0.3).
- P1 (no control): bedGraph of pseudobulk CPM; macs3 bdgpeakcall -l 1000 -g 1000 with cutoff = the TF's 20,000th-highest bin value (comparable peak numbers across TFs); top 5,000 peaks by peak score.
- P2 (ATAC background): treat = pseudobulk counts; control lambda per bin = max(ATAC in the bin, ATAC mean over +/- 5 kb, genome ATAC mean), ATAC scaled to the TF's total pseudobulk count; macs3 bdgcmp -m qpois; macs3 bdgpeakcall -c 2 (q <= 0.01) -l 1000 -g 1000; top 5,000 by score.
- P3 (pseudo-fragments): one read per positive cell x bin at the bin centre; macs3 callpeak -f BED --nomodel --shift -500 --extsize 1000 --keep-dup all -g hs -q 0.05, P3a without control, P3b with the ATAC tagAlign as control (-c); top 5,000 by -log10 q, then signal. Reads sit on bin centres, so MACS's shift model is not meaningful; the local lambda (1 kb / 10 kb) is what this tests.
- Local contrast: per TF, imputed pseudobulk at the bins of its top-5,000 lab summits vs the mean of the bins 2 kb on either side (median ratio, and share of summits with ratio > 1).
Evaluation exactly as m46 main: summit (bdgpeakcall: peak start + summit offset; callpeak: summit) through the Stage 1 link rule, padding 0 / 10 kb / 50 kb; (a) top-5,000-peak lists, (b) equal list size to the lab list (top peaks by score, smallest N reaching the lab list size). Recall, matched gene shuffle (1,000, seed 20261118) gap and p for all 63 / without NRF1, E4F1, DNMT1 / without broad TFs; per-TF number above the shuffle (p < 0.05, TFs with >= 10 Perturb-seq genes); Jaccard with lab lists; lab, I2 and I2loo rows alongside.
Verdict: MACS peaks beat imputed bins if their equal-size gap over the shuffle exceeds I2loo's; beat the lab peaks if it exceeds the lab gap.
