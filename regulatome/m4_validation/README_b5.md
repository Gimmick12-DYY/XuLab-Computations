# B5: second Perturb-seq comparison ("second comparison, after the first was seen")
Declared spec (verbatim, from regulome_validation/r2b_spec.md):
"Second Perturb-seq comparison (declared now, run once after manifest v4). Same B3 machinery, same arms, same gene universe, same expression-matched random sets, same ATAC-only and binding-only nulls at the list's size. Scored for every TF with >= 10 R2b genes in the universe. Primary pooled test: across-TF mean effect and bootstrap CI for (a) all R2b lists, (b) R2b lists of the 72 non-specific TFs, each versus 0, versus ATAC-only and versus binding-only. Secondary: same for the 7 specific TFs; and paired comparison R2b versus direct top-1,000 effect over TFs that have both. Reported as 'second comparison, after the first was seen', with the first-comparison result beside it. No tuning of thresholds after the run; if it fails, that is the result."
Design-thread rulings (2026-11-06): runs against R2b v5 (manifest v5 235173bd...), not v4. Primary set = all eligible lists; expressed-only (B3 not_expressed filter) is a labelled sensitivity. Random sets use B3's seed (20261103 per arm) and procedure; the draws differ from B3's because fewer lists are scored, so the call order differs. Direct top-1,000 effects are taken from b3b4/per_tf_effects.tsv, not recomputed. The B3 direct-tier pooled results are written beside (first_comparison_b3_direct.tsv).
Script ../b5_r2b.py, run by ../run_b5.sbatch; outputs here; manifest_b5.sha256 covers the outputs, this README and the script. b3b4/ and the v3/v4/v5 folders are not touched.
