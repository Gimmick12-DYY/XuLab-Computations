# Regulome edge table (spec, 2026-11-11)
One row per TF and gene. Descriptive output for Figure 5; nothing here is fitted to or compared with Perturb-seq.
1. Universe: the 19,807 ABC genes on primary chromosomes and all 79 panel TFs. Primary link set: canonical ABC with real Hi-C (m2c_abc_canonical HEK293T_hicfixed, ABC >= 0.02). The m2_abc power-law link set is a second copy of the table. Raw HITAG binding, recounted on the candidate elements as in m7_step2 Amendment 4. Imputed binding is not used.
2. Binding columns per TF and gene: promoter (self-promoter elements), distal (linked non-promoter elements), total; log1p CPM. n_promoter_elements, n_distal_elements, and whether any distal link overlaps a Peakachu 0.7 loop anchor pair (loop_supported).
3. Edge p (depth- and accessibility-matched null): for each TF, 200 pseudo-TF draws, each placing the same number of fragments on candidate elements within the same ATAC decile x H3K27ac decile (reuse the m7_step2 pseudo-TF code; state the matching used). p = (1 + number of draws with total binding >= observed) / 201, per gene. BH within TF gives q. Also the same p for promoter and distal separately. called = q <= 0.05 (total).
4. rank_in_tf: percentile of the gene's total binding among all genes for that TF. in_v8: membership of the frozen v8 top-1,000 list.
5. shared_by: number of the 79 TFs with called = true at the gene. Also shared_by_deep: the same count over the 27 high-tertile TFs only.
6. TF-level columns joined on: cells, depth tertile, d and tier from per_tf_floor_test.tsv (claim tier d >= .04; above null; not supported), annotated sign with confidence from tf_sign_annotation.tsv. No learned sign column (the m7_step2 model was null on raw binding).
7. partner: for each pair in m7_step2 pair_list.tsv, flag genes where both members are called and both have binding on at least one common element.
8. Summaries to report, whatever they show: (a) number of called genes per TF against cells per TF, with Spearman, for all 79 and within the high tertile; (b) distribution of shared_by over genes (quantiles; number of genes called by >= 40 TFs; by 1 to 5 TFs); (c) fraction of each TF's called genes that are called by <= 5 TFs; (d) overlap of called genes with the v8 list per TF (median, range); (e) for the 20 claim-tier TFs, the same four numbers in one table.
9. Declared lookups, reported in full whether or not they match expectation. TF to genes: for E4F1, the rows for DLAT, DLD, MPC1, PDPR, CHEK1; for MLX, TXNIP and ARRDC4; for NFYA, CCNB1 and CDK1; for E2F3, CCNE1 and MCM2 to MCM7; each with binding, rank_in_tf, p, q, called, shared_by. Gene to TFs: for EZH2, MYC, CCNE1, CDK1, CCNB1, TXNIP, LDLR, HMGCR, CDKN1A, CDKN2A, ACTB and GAPDH, the list of TFs with called = true (tier, rank_in_tf, q), shared_by and shared_by_deep. These expectations come from the literature as recalled and have not been verified with citations; the table reports what is found and makes no claim.
10. Outputs: edge_table_hicfixed.tsv.gz and edge_table_powerlaw.tsv.gz (gitignored if large; record sha256), summaries.tsv, lookups.tsv, README.md.
