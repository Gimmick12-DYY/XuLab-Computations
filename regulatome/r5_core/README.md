# R5 Regulome core (manifest v7)
Spec: SPEC.md. Script: r5_core.py, run by r5_core.sbatch. Outputs: lists/<TF>.tsv.gz, tf_summary.tsv, checks/, edges/loop_anchor_promoter.tsv.gz (copied from regulatome/r5_two_layer/edges/, built by r5_prep.py). manifest_v7.sha256 covers all outputs and scripts here except logs, written last. No Perturb-seq data is read.

- ABC provenance: unchanged. regulatome/m2_abc (ABC v1.1.2, ATAC-only activity from omniatac_merged.tn5.tagAlign.gz, power-law contact gamma 1.024, scale 5.96), Predictions_powerlaw/EnhancerPredictionsFull_thr0.02.tsv, 104,071 links over the 159,965 active elements, self-promoter links included.
- Reads: raw read 5' ends per element per cell, summed over the TF's cells, from regulatome/gate1/cellmats/<TF>.raw.npz (gate1_prep.py, which counts with the m1_binding/v2 rule: + strand 5' end = start, - strand 1 bp 5' end). CPM = reads at the element / all reads of the TF's cells (cells.npz "reads") x 1e6. S_pool uses the same counts summed over the other 78 TFs.
- Relation to the B3/B4 ablation "raw_direct" arm: that arm is R2's direct score, sum over the same ABC links of the Gate 1 v2 element residual log2((obs + .5)/(mu + .5)) (GLM on ATAC, pooled panel, width, GC, mappability) x ABC, with Cicero gains (kappa 1). R5 core uses the raw CPM itself (no residual, no GLM, no Cicero), so it is not adjusted for accessibility; S_atac and S_pool are given alongside for that comparison.
