# Strong-phenotype knockdowns (X-Atlas/Orion authors' filter) and the simple-model comparison (spec, 2026-11-11)
Label: "diagnostic, benchmark already read". HEK293T Perturb-seq only, data already on Longleaf. Yuyang agreed to use the authors' own filter to define usable knockdowns and asked for a simple initial comparison with the knockdowns taken at face value.
A. Authors' criteria (preprint Methods, as relayed): perturbations with strong phenotypes = (1) >= 25 cells, (2) >= 30% on-target knockdown, (3) significant q in a binary classifier (L1 logistic regression on highly variable genes, perturbed vs non-targeting cells, held-out cells; >= 100 cells to be assessed), (4) non-zero target counts in the training split of non-targeting cells. The per-perturbation classifier results are not released (figshare 29190726 file list and the Hugging Face dataset contain no classifier table; regulatome/phase1/README.md already records paper_classifier_q = not_released; the bioRxiv supplementary page could not be reached from Longleaf). The classifier is therefore reproduced on our streamed cells (data/x_atlas_orion/panel_ntc_cells; cells with pass_guide_filter):
- per knocked-down gene (77 with units; CBX1/CBX3/CBX5 and ZUP1 separately, then mapped to panel names; a panel TF passes if any of its genes passes), its cells vs the same number of non-targeting cells drawn from the same GEM samples (seed 20261111);
- features: 2,000 highly variable genes computed on 20,000 non-targeting cells by a seurat_v3-style rule (log variance vs log mean fitted by a binned running mean, standardised variance ranked; scanpy is not installed, so this is an approximation), target gene(s) removed (target-ablated); log1p CP10k, standardised on the training split;
- 70/30 split stratified; L1 logistic regression (liblinear, C = 0.1); held-out AUC; null = labels permuted within the training split, 200 draws; p = (1 + #null AUC >= observed) / 201; BH over perturbations; q < 0.05 significant;
- negative control: 20 sets of 300 non-targeting cells against other non-targeting cells, same pipeline (expected pass rate about 0).
- knockdown %: from regulatome/phase1/panel_tf_xatlas_status.tsv (knockdown_pct: 1 - perturbed/NTC mean CP10k of the target, GEM-matched); cells: pass_guide_filter cells.
Output per TF: cells, knockdown %, AUC, q, each criterion and strong-phenotype yes/no, beside our split-half ceiling, benchmark-testable flag (m10 Amendment 1 F1), depth tertile, specificity tier; counts per criterion; overlap with ceiling >= 0.2 (19 TFs) and with the 9 testable TFs.
B. Initial comparison, simple model only, Arm 2 raw per-TF z, genes >= 10% NTC detection, own gene removed: P = sum over canonical ABC links (ABC >= 0.02, self-promoter included) of lab q <= 0.05 peak signalValue x ABC score (m11), and the promoter-only version. Per TF: OR of the top-1,000 P genes among top-5% |z| responders (gene-bootstrap 95% interval, 1,000 draws) and Spearman(P, |z|), beside promoter-ATAC-decile x CpG matched genes (200 draws) and the swapped TF (m7_step2 mis0, same depth tertile); decile table. Pooled over passing TFs: median (OR - matched) with TF-bootstrap interval (2,000), fraction of TFs above matched and above swapped, and a Mantel-Haenszel OR over all (TF, gene) entries stratified by TF with its 95% interval; the same for non-passing TFs as the contrast, reported whichever way it comes out. Figure (PNG + SVG, Arial): per-TF OR with intervals sorted, passing TFs coloured, matched OR as grey ticks; inset NRF1 deciles; promoter version blue, full (promoter + enhancer) orange.
Secondary (labelled): the m10 per-TF promoter summary and the m15 statistic restricted to strong-phenotype TFs.
