## Amendment 2, 2026-11-11, before any number of G1-G3 (diagnostic, benchmark already read; no model fitting)
Open chromatin = the canonical ABC candidate elements (m2c HEK293T_hicfixed EnhancerList, 142,706 elements; MACS2 on merged ATAC plus TSS +/- 250 bp). Fragments = raw per-TF fragment 5' ends (as m7_step2 Amendment 4). Promoter site = within 1 kb of any GeneList TSS; distal = otherwise.
G1. Own-motif sites: FIMO (MEME 5.5.7, uniform background) of each TF's HOCOMOCO v11 motif (as m9 section B) over the open-chromatin sequences, p < 1e-4, site centre. ChIP sites: bulk ChIP peak summits (narrowPeak start + column 10) lying in open chromatin; all bulk ChIP peak files on Longleaf are ENCODE HEK293 except NFYA (K562); the HEK293T CTCF reference has no peak file and is not used here. Background per site list: the same number of positions drawn uniformly inside open-chromatin elements of the same ATAC decile (element ATAC.RPM deciles), in elements with no site of that list (seed 20261111). Per TF: on-target fraction = fragments with 5' end within +/- 100 bp of a site / all fragments; the same for the pooled other 78 TFs' fragments and for the background positions; enrichment = own fraction / background fraction and own fraction / pooled-other fraction, each with a 1,000-draw bootstrap over sites (and background positions); all, promoter and distal sites separately.
G2. The 9 testable TFs of Amendment 1 F1; OR test as there (Arm 2, r1, top 5% |z|; gene-bootstrap 95% interval; matched, pseudo-TF, swapped controls). Lists: (i) genes with one of our q <= 0.05 MACS2 peak summits within 1 kb of the TSS, all of them (n reported); matched control of equal n; pseudo-TF = n genes drawn with probability proportional to promoter ATAC (20 draws); (ii) per gene, fragments within TSS +/- 500 bp whose 5' end lies within +/- 100 bp of an own-motif site found by FIMO (p < 1e-4) in that promoter; rank by count, top 1,000 or all nonzero if fewer (TFs with a HOCOMOCO v11 motif only); pseudo-TF = multinomial over genes proportional to promoter ATAC at the same total; (iii) ratio = (TF promoter CPM + 1) / (pooled other-78-TF promoter CPM + 1), TSS +/- 500 bp, CPM of each TF's total reads, pooled = summed counts over summed totals; top 1,000; pseudo-TF as (ii). Swapped TF = the m7_step2 mis0 partner's list built the same way. For CTCF: number of the 117 bulk-ChIP-positive responders (HEK293 ChIP top 1,000 and top-5% response) recovered by each list.
G3. CTCF: group A = genes in the HEK293T ChIP top 1,000 at promoters and below the 50th percentile of our raw promoter rank; group B = genes in our raw top 1,000 and not in the HEK293T ChIP top 1,000. Per group: n, median and IQR of promoter ATAC, CpG-island fraction, pooled-panel promoter CPM (all 79 TFs), our CTCF promoter fragments; Mann-Whitney p between groups. Descriptive.
