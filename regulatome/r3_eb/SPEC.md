# Stage B: graded empirical-Bayes Regulome (R3, manifest v6)
Approved by Yuyang ("Yeah do stage B, we don't want this gate", 2026-11-06 22:15Z). Spec as given by the design thread (source: regulome_validation/stage_b_spec.md):

1. INPUTS (read only): the 159,965 ABC-mapped active elements from R2/R2b. Gate 1 v2.1 raw reads y_te. Expectation mu_te: the Gate 1 v2.1 Poisson GLM, refit ONCE with one added covariate, log1p(h_e), where h_e = number of panel TFs (leave-TF-out) whose raw CPM at e is above that TF's own 90th percentile; report the HOT coefficient and its SE per TF. ABC links m2_abc (104,071), Hi-C loops Peakachu 0.7 (GSE216399 WT), the TSS table from R2, union ATAC.
2. ELEMENT EB, per TF t: phi_t by NB method of moments on elements with mu >= 5 (Poisson if phi <= 0). b = log((y+.5)/(mu+.5)), s = sqrt(1/(y+.5) + phi), scored for mu >= 1. ashr per TF independently (normal mixture, point mass at 0, unimodal prior at 0). Record beta, posterior SD, lfsr per element; pi0 and tau (prior SD) per TF. Supporting element = beta > 0 and lfsr <= 0.10; record negatives too.
3. GENES: primary S_B = sum over beta>0 of beta * exp(-d/10kb), elements within 100 kb of the TSS; elements beyond 20 kb count only with an ABC link to g or a Hi-C loop anchor paired with g's promoter anchor; no Cicero. Secondary S_ABC = sum of beta * ABC over links with beta > 0. List a gene when at least one supporting element carries >= 50% of its score AND it has >= 2 supporting elements OR 1 within 5 kb of the TSS. Rank by S_B, cap 1,000, keep the uncapped count; empty lists OK. No tiers. Report per TF: tau, pi0, n_supporting, n_list, median lfsr.
4. MODULES: pool y and mu over members for PRC2 core (EZH2 MTF2 PCGF6, flag not_PRC2_enriched), NuRD (MBD3 core) and the WIZ/ZNF644 group (DR1 THAP6 CHAMP1 WIZ ZNF644 SRCAP); same model.
5. DEPTH LABEL: TFs with >= 20,000 reads: binomially thin to 10/25/50/75% and refit 1-2; record 1-pi0 and n_supporting. Fit 1-pi0 vs reads across TFs. "Undetectable at this depth": reads below where the curve first exceeds 2x the panel median of 1-pi0. "Accessibility-equivalent": reads above that and 1-pi0 < 0.01. Otherwise "specific (graded)".
6. INTERNAL VALIDATION (no Perturb-seq): AUPR of beta vs raw CPM vs Gate 1 residual against bulk ChIP for the 7 TFs with open-chromatin negatives; split-half PPC calibration; HPA HEK293 nTPM Spearman; HOT stratification (supporting share at h >= 20; list stability without HOT loci); ATAC-only proximal baseline list per TF.
7. OUTPUTS under regulatome/r3_eb/: elements/<TF>.tsv.gz, genes/<TF>.tsv, tf_summary.tsv, modules/, validation/, README.md; manifest_v6.sha256 over all outputs and scripts, written LAST; scripts refuse to run if v6 exists.
8. RESOURCES AND RULES: new folder only; v1-v5 and b3b4/b5 untouched; never read Perturb-seq; code committed by name under the user's git identity.

## Implementation notes (choices the spec leaves open)
- Elements, covariates, GLM (design and IRLS) are copied from gate1/v2_1/gate1_v21.py; the HOT covariate is added as one extra column; SE from the inverse Fisher information at convergence.
- h_e for module fits uses all panel TFs; reads = summed reads over each TF's cells (Gate 1 cellmats).
- NuRD "MBD3 core" = MBD3, RBBP4, RBBP7 (the R1 NuRD seed module). Module mu = sum of members' own HOT-GLM expectations.
- TSS = ABC TargetGeneTSS per gene (the gene universe R2 uses); distance from element midpoint. Hi-C pairing: element overlaps one anchor of a Peakachu 0.7 loop (5 kb or 10 kb) and the other anchor overlaps TSS +/- 1 kb.
- Gene list: "carries >= 50% of its score" = the largest single supporting element's beta*exp(-d/10kb) over S_B; median lfsr = median lfsr of each listed gene's top element.
- Depth curve: isotonic (non-decreasing) regression of 1-pi0 on log10 reads over full-depth TFs and all thinned fits; reads* = first grid point where the fit exceeds 2x the median full-depth 1-pi0. Thinning is binomial at element level (seed 20261106).
- PPC: Gate 1 v2.1 first split (seed 20261029 + TF index); EB fitted on half A (mu scaled by half reads, phi re-estimated); 200 posterior draws (normal approximation to the posterior) give a 90% predictive interval for half-B counts; reports coverage and the slope of half-B log ratios on half-A beta.
- AUPR: positives = active elements overlapping a bulk ChIP peak (same 7 files as downstream/imputation_auprc/imputation_auprc_bulk.py); negatives = all other active (open) elements; unscored elements get beta 0. Gate 1 residual = element log2((y+.5)/(mu_v2.1+.5)) with the original v2.1 GLM.
- HPA: HEK293 nTPM from data/hpa/rna_celline.tsv.zip; Spearman of S_B vs nTPM over genes with S_B > 0.
- HOT stratification: h >= 20 (leave-TF-out); list stability = Jaccard of the capped list with and without elements at h >= 20.
- ATAC-only proximal baseline: genes ranked by sum of union-ATAC CPM * exp(-d/10kb) over the same element-gene pairs; top n_list genes; overlap with the list.
