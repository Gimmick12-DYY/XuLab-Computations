Coordinated binding network · SEdb SE_02_1951 (HEK293T, hg38)

Do co-binding cliques prefer super-enhancers?

Capture: yes. Against 1,000 sets of random same-size genome windows, 99% of SEs carry a network peak (vs 76%), 68% carry cliques from ≥2 TFs (vs 19%, 3.6×) and 29% from ≥5 TFs (vs 2.6%, 11×), all p = 0.001. 60 of 68 TFs individually hit SEs more than random (median 5.6×).

Enrichment beyond peak density: no. 87% of the 342 SEs contain a clique region, and 28% contain cliques from 5 or more TFs. That is far above same-size windows placed on random active chromatin (8%). It disappears when the comparison windows hold the same number of network peaks as each SE: SEs then have slightly fewer clique TFs than expected (3.56 vs 3.96 per SE, one-sided p for enrichment = 1.00, for depletion = 0.001).

How the nulls were built

  • Active-chromatin null. Each SE is moved, keeping its size and chromosome, to a window centred on a random TssA, EnhA or EnhG ChromHMM segment. This controls for "active chromatin" but not for how many peaks the window holds.
  • Density-matched null. Each SE is matched to non-SE windows of the same size whose network-peak count (summed over all TFs' Cicero network nodes) is within ±10% of the SE's. Windows come from the same chromosome when at least 50 matches exist (290 SEs) and genome-wide otherwise (48). Matching worked: mean peak count 17.4 in SEs vs 17.1 in null windows.
  • Per-peak check. Within each TF and local peak-density decile, a clique peak is 1.21× more likely than a non-clique peak to sit in an SE (Mantel–Haenszel, p = 2×10⁻⁸). The direction is inconsistent across TFs (33 of 52 up, sign test p = 0.07). At the level of whole SEs, the density-matched window test above is the more direct test, and it is negative.

What this means

Cliques need several co-accessible peaks within 1 Mb, so they form wherever peaks are dense. SEs are dense peak clusters, which explains the high capture. Once density is equal, SEs are not special clique sites. The same holds for the other annotations: GO of clique target genes against each TF's own network genes is empty (1 of 39 TFs), and the promoter, enhancer and A-compartment preferences shrink to about 1.05–1.1× after density matching.
